# cobitx.com (repo: cobitx)

Website of **Cobitx Technologies**, the owner's software house (sole proprietorship, Muridke).
Owner: Syed Waqas Asim, publicly known as Waqas Gilani (GitHub `rohaniyet`).

## Working rules

- Plain static HTML on **GitHub Pages** (`CNAME` = cobitx.com, DNS on Cloudflare). No build step:
  a push to `main` publishes the site. **Ask the owner before every push.**
- Site text is **English only**. Keep token use low: open only the page the task needs.
- **This repo is public** and must stay public (GitHub Pages on the free plan needs it). Never
  commit keys, passwords or client data.
- GitHub Pages publishes every file in the repo. Non-site files go in a dot-folder (this file
  lives in `.claude/` for that reason), which Pages does not publish.
- Never mention the owner's taxation job (his employment) anywhere on the site.

## Files

- `index.html`: the main site (software house: custom ERP, web and AI development, plus tax and
  registration services).
- `tax-return.html`: online income tax return filing page with the published fee card.
- `inv.html`: Cobitx invoice generator (internal tool, but publicly reachable).
- `sitemap.xml`, `robots.txt`: add every new public page to the sitemap.
- `pinterest-ec20b.html`: Pinterest site verification. Do not delete.
- `logo.png`, `QR.png`.
